# Atribuição

Este snapshot reúne código de projetos externos sob GPL-3.0-or-later. Créditos mantidos conforme os repositórios de origem:

- **Marvisak/VIctory** — runtime base (compatibilidade Xbox Series X|S no Windows).
- **ElSeba0811/VIctory**, branch `codex/gtx-upstream-update` — `source/gtxfallback`, fallback mesh→compute (PR `Marvisak/VIctory#2203`) e `translate --cache --pipelines`.
- **L1DRE/VIctory**, branch `gtx1070/mangrove-2203` — `source/mangrove2203`, port do #2203 para mangrove.
- **PastiiJay/klbf-lab** e **LoverCatys/ruff-lab** — técnica de prebuild offline que salva progresso e evita crashes do compilador AMD (aplicada ao `RUNBOOK-mesh580.md`).
- **Belobug/VIctory-Belobug-AMD** — referência de tratamento de crash do compilador e iluminação AMD.
- **fxceless/victory-fork** — base de vários forks locais.

Os HEADs exatos dos fontes copiados estão em `evidence/source-heads.txt`. Nenhum binário, jogo ou cache foi redistribuído. Licença: `LICENSE` (GPL-3.0).
